# Hi, I'm King Jethro 👋

**Software Engineer · Bug Bounty Hunter · Systems & AI Builder · Athlete**

I build developer tooling, autonomous AI agents, native utilities, and interactive 3D web systems, alongside offensive security and vulnerability hunting. Rather than sticking to comfortable boilerplate, I focus on systems thinking — building tools that eliminate friction for developers and securing digital infrastructure.

---

### What I'm Actively Building

- **[Automator](https://github.com/kingjethro999/automator)** — A watched-mode AI computer operator featuring an observed UI execution timeline, AI cursor overlay, and desktop/OS automation skills.
- **[Zyrk](https://github.com/kingjethro999/zyrk)** — A storage-efficient Node package manager built around a global content-addressable store and symlink/hardlink resolution.
- **[Prompt Dock](https://github.com/kingjethro999/promptdock)** — Local-first AI prompt engineering workspace with structured shape-contracts, live previews, and multi-provider fallback chains.
- **Bug Bounty & Security Research** — Web application vulnerabilities, exploit feasibility verification, and secure execution boundaries for autonomous agents.
